
# Introduction


[MisoDoc2](https://github.com/juliendehos/misodoc2) generates a documentation
from MD files. It supports the [CommonMark](https://commonmark.org/)
specification and a few extensions.

MisoDoc2 can run a server that builds the documentation dynamically (useful for
writing the documentation). It can also build static HTML files (for deploying
the final documentation).

MisoDoc2 is written in Haskell using the [miso](https://haskell-miso.org/) and
[commonmark](https://hackage.haskell.org/package/commonmark) libraries. It is
inspired by [mdBook](https://rust-lang.github.io/mdBook/).
